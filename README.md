## Body Fat Prediction using R

## Project Overview
This project uses Multiple Linear Regression to predict body fat percentage based on physical measurements and personal attributes.

The main objective is to analyse body composition data, explore relationships between variables, and build a regression model to estimate body fat percentage.

## Technologies Used
- R Programming
- RStudio
- ggplot2
- Multiple Linear Regression

## Dataset
The dataset contains body composition measurements, including:
- Age
- Weight
- Height
- Neck
- Chest
- Abdomen
- Hip
- Thigh
- Knee
- Ankle
- Biceps
- Forearm
- Wrist

## Project Workflow
1. Data loading and inspection
2. Data cleaning and missing value handling
3. Exploratory Data Analysis
4. Data visualization
5. Train-test splitting (70:30)
6. Multiple Linear Regression
7. Prediction on test data
8. Model evaluation using RMSE and R-squared

## Visualizations
Four visualizations are included:
- Body Fat Percentage Distribution
- Age vs Body Fat Percentage
- Body Fat Boxplot
- Actual vs Predicted Body Fat Percentage

## Model Performance

| Evaluation Metric | Result |
|---|---:|
| RMSE | 4.292 |
| R-squared | 0.7209 |
| R-squared Percentage | 72.09% |

## Conclusion
The Multiple Linear Regression model achieved an R-squared value of 72.09% and an RMSE of 4.292 on the test dataset.

This project helped develop practical knowledge of data preprocessing, exploratory data analysis, regression modelling, data visualization, and model evaluation using R.
